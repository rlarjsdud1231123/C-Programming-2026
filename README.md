## 제어문 종합 실습

`제어문 종합 실습.c` 파일에는 다음 5개의 실습이 포함되어 있습니다.

1. 거듭제곱 구하기
2. 팩토리얼 구하기
3. 피보나치 수 구하기
4. 여러 점수의 평균 구하기
5. 이중 반복문을 이용한 삼각형 별 출력

실행 시 1~5번 중 하나를 선택하여 해당 실습을 실행할 수 있습니다.

## 참고

- 10번과 12번은 하나의 파일에 함께 구현되어 있습니다.
- 10번의 `switch-case`를 이용한 월별 일 수 계산에 12번의 윤년 판별 기능을 추가한 형태입니다.
- 7번 화폐 단위 분해는 기본 실습에 추가하여 10,000원, 5,000원, 1,000원, 500원, 100원, 50원, 10원 단위까지 계산하도록 구현했습니다.
